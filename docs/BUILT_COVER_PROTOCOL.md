# Protocol for variation in the tree cover association with built cover

Stage 2 compares a fixed ten-percentage-point change in tree cover at two built-cover references. Use the same seven Landsat dates, 500 m study grid, Esri classes and primary QA and WorldCover rules as Stage 1. The 2025 baseline and its window-selection history are available as prior evidence. The new contrast and its analysis population are determined from cover, geometry and date availability before fitting the temperature models. [Research roadmap](RESEARCH_ROADMAP.md) · [Prior local analysis](LOCAL_COMPARISON_RESULTS.md)

## Map and select the common support

Map the joint distribution with one count per usable grid cell and bins five percentage points wide. Within each candidate built-cover band, count cells near either tree endpoint and find same-date, same-block low and high tree cells separated by eight to twelve percentage points. Count distinct 4 km blocks and block-date combinations supporting both ends. Repeat the count with the Stage 1 distance and balance rules of at most 2 km between cell centers, at most a five-point difference in built cover and at most a ten-point difference in land share. [Common support and interaction diagnostics](https://doi.org/10.1017/pan.2018.46)

Use candidate tree starts from 0% to 30% in increments of 2.5 points, with the other endpoint ten points higher. Search built-cover references from 25% to 90% in five-point increments. The main support audit allows up to five points around each tree endpoint and a less than ten-point deviation from each built reference. Require a gap of at least 20 points between the two built references to create distinct bands. Reserve 2.5 points for other land cover at the exact higher-tree reference so the requested comparison stays within the feasible composition. Require cells near each of the four reference combinations in a tighter neighborhood of 2.5 tree points and five built points.

Choose the contrast with the most independent spatial blocks containing both built bands with both ends on a common date. Break ties using the number of shared block-dates, the smallest count across the four tighter endpoint neighborhoods, and the built-cover separation. Use the candidate ordering as the last tie break. The date count measures temporal availability, and the block count measures spatial replication. Freeze the eligible cell-date IDs before estimating temperatures. The primary model includes rows inside the selected tree interval and each corresponding built band for the block-dates with endpoint support in that band. A shared-area fit then uses the block-dates that support both bands. The support audit also counts the stricter Stage 1 pairs and wider and tighter windows.

## Estimate the difference in associations

Give each date equal total weight. Fit an additive regression with separate quadratic terms for tree and built shares, land share, and within-block-date intercepts. The primary interaction model adds the product of the centered tree and built fractions to the same additive terms. For each built reference, predict the difference in LST from the same lower tree share to the same upper tree share, holding land share and the block-date intercept fixed. Subtract the contrast at the lower built reference from the one at the higher built reference. A negative difference means the tree association is more negative at the higher built reference.

Estimate percentile intervals with 1,999 spatial block draws, keeping all dates from a sampled block together and recalculating date weights. Compute the higher-minus-lower difference within each resample so it incorporates the covariance between the two fitted contrasts. Report how many draws retain the dates, contain both built bands and support a full-rank fit. Treat results from the small shared-area subset as sensitivity evidence. [Block resampling](https://doi.org/10.1214/009053606000000551) · [Uncertainty with few clusters](https://escholarship.org/uc/item/1jq5d0pq)

## Check modeling and spatial sensitivity

Compare the additive and primary interaction fits on the same rows. Fit a linear product model and a piecewise linear model with a bend halfway between the tree endpoints and one halfway between the two built references. In the piecewise model interact both tree basis terms with both built basis terms. Estimate the same finite contrasts under every model.

Check the shared-area subset, a tighter support window, the 2 km and 6 km local blocks, the shifted 4 km origin, the nested 8 km bootstrap, the Esri water mask, and the cloud-distance and 4 K product-uncertainty screen. Compare the case-weighted fit and record the effects of removing each date and each block. Reuse the Stage 1 minimum-cost disjoint matching on the audited near-neighbor links within each built band. Compare pair contrasts on dates observed in both bands and, when available, on identical block-dates. Sparse pair comparisons describe their specific locations.

Report temperature contrasts for the selected cover levels and the seven clear-sky overpasses. Increases in tree share at fixed built share imply differences in the remaining land-cover mix. The fitted contrast depends on sample support, the response curve and the geographic variation available within blocks.
